# Beauty Enhance ✦

تطبيق ويب لتحسين الصور وتجميلها — يعمل بالكامل داخل المتصفح، دون رفع الصور إلى أي خادم.

A browser-based photo enhancer: auto-enhance, portrait retouching, 2×/4× upscaling, old-photo restoration and color correction. Everything runs locally on the device.

## المزايا / Features

| الوضع | ماذا يفعل |
|---|---|
| ✦ تلقائي (Auto) | توازن الألوان + إزالة التشويش + الحدّة + الوضوح |
| ♡ تجميل (Beauty) | تنعيم البشرة فقط (يكتشف لون البشرة ويحمي العيون والشعر) + إضاءة ناعمة |
| ◈ وضوح HD | تكبير 2× مع استعادة التفاصيل |
| ⟲ صورة قديمة | إزالة تشويش قوية + تصحيح البهتان والألوان |
| ❋ ألوان | توازن الأبيض + حيوية الألوان |
| ☾ إضاءة | تفتيح الصور المظلمة مع إزالة التشويش |

### 🤖 أدوات الذكاء الاصطناعي

| الأداة | أين تعمل | التكلفة |
|---|---|---|
| ✂ إزالة الخلفية (شفافة / بيضاء / ضبابية / لون) | داخل المتصفح — نموذج ISNet من [@imgly/background-removal](https://github.com/imgly/background-removal-js) (~80MB يُحمَّل مرة واحدة) | مجاني |
| 🎨 تلوين الصور القديمة | داخل المتصفح — نموذج [DDColor-tiny](https://huggingface.co/edgetools/ddcolor) (~135MB يُحفظ بعد أول تحميل) — أو عبر السحابة | مجاني (أو سحابي اختياري) |
| ☺ ترميم الوجوه (CodeFormer) | سحابي عبر [fal.ai](https://fal.ai/models/fal-ai/codeformer) | حوالي 0.002$ لكل ميغابكسل |

**إعداد fal.ai:** أنشئي حساباً في fal.ai ← Dashboard ← Keys ← أنشئي مفتاحاً، ثم الصقيه في «إعدادات الذكاء الاصطناعي» داخل التطبيق. يُحفظ المفتاح في جهازك فقط.

> ⚠️ المفتاح يُستخدم مباشرة من المتصفح، لذا لا تنشري التطبيق مع مفتاحك مضمّناً فيه، ولا تشاركي المفتاح.

- مقارنة «قبل / بعد» بالسحب
- ضبط يدوي لعشرة إعدادات
- تكبير الدقة 1× / 2× / 4×
- حفظ بصيغة JPG أو PNG (وعلى الجوال تظهر قائمة المشاركة لحفظها في المعرض)
- واجهة عربية / إنجليزية، ووضع فاتح / داكن تلقائي

## التشغيل / Run

لا يحتاج إلى أي تثبيت. شغّل خادماً بسيطاً من مجلد المشروع:

```bash
python3 -m http.server 8000
```

ثم افتح `http://localhost:8000`.

للنشر المجاني: من إعدادات المستودع على GitHub ← **Pages** ← اختر الفرع ثم المجلد `/ (root)`.

## كيف يعمل / How it works

`js/enhance.js` يحتوي على خوارزميات معالجة الصور الكلاسيكية (بدون ذكاء اصطناعي عصبي):

`js/ai.js` يحتوي على أدوات الذكاء الاصطناعي (ES module) ويستخدم onnxruntime-web.

- **Guided filter**: تنعيم يحافظ على الحواف (لإزالة التشويش وتنعيم البشرة)
- **YCbCr skin mask**: اكتشاف مناطق البشرة
- **Unsharp mask**: الحدّة والوضوح
- **Gray-world + percentile levels**: تصحيح الألوان والتباين

تعمل المعالجة داخل Web Worker حتى لا تتجمد الواجهة.

> ملاحظة: التطبيقات التجارية مثل Remini تستخدم نماذج ذكاء اصطناعي ضخمة تعمل على خوادم، وتستطيع «اختراع» تفاصيل غير موجودة (مثل ملامح وجه واضحة من صورة ضبابية جداً). التحسين المحلي في هذا التطبيق يحسّن التفاصيل الموجودة فقط، أما «ترميم الوجوه» السحابي فيستخدم نموذج CodeFormer الذي يعيد بناء ملامح الوجه فعلاً.
