# Beauty Enhance ✦

تطبيق ويب لتحسين الصور وتجميلها — يعمل بالكامل داخل المتصفح، دون رفع الصور إلى أي خادم.

A browser-based photo enhancer: auto-enhance, portrait retouching, 2×/4× upscaling, old-photo restoration and color correction. Everything runs locally on the device.

## المزايا / Features

| الوضع | ماذا يفعل |
|---|---|
| ✦ تلقائي (Auto) | توازن الألوان + إزالة التشويش + الحدّة + الوضوح |
| ♡ تجميل (Beauty) | تنعيم البشرة فقط (يكتشف لون البشرة ويحمي العيون والشعر) + إضاءة ناعمة |
| ◈ وضوح HD | تكبير 2× مع استعادة التفاصيل |
| ⟲ صورة قديمة | إزالة تشويش قوية + تصحيح البهتان والألوان |
| ❋ ألوان | توازن الأبيض + حيوية الألوان |
| ☾ إضاءة | تفتيح الصور المظلمة مع إزالة التشويش |

- مقارنة «قبل / بعد» بالسحب
- ضبط يدوي لعشرة إعدادات
- تكبير الدقة 1× / 2× / 4×
- حفظ بصيغة JPG أو PNG (وعلى الجوال تظهر قائمة المشاركة لحفظها في المعرض)
- واجهة عربية / إنجليزية، ووضع فاتح / داكن تلقائي

## التشغيل / Run

لا يحتاج إلى أي تثبيت. شغّل خادماً بسيطاً من مجلد المشروع:

```bash
python3 -m http.server 8000
```

ثم افتح `http://localhost:8000`.

للنشر المجاني: من إعدادات المستودع على GitHub ← **Pages** ← اختر الفرع ثم المجلد `/ (root)`.

## كيف يعمل / How it works

`js/enhance.js` يحتوي على خوارزميات معالجة الصور الكلاسيكية (بدون ذكاء اصطناعي عصبي):

- **Guided filter**: تنعيم يحافظ على الحواف (لإزالة التشويش وتنعيم البشرة)
- **YCbCr skin mask**: اكتشاف مناطق البشرة
- **Unsharp mask**: الحدّة والوضوح
- **Gray-world + percentile levels**: تصحيح الألوان والتباين

تعمل المعالجة داخل Web Worker حتى لا تتجمد الواجهة.

> ملاحظة: التطبيقات التجارية مثل Remini تستخدم نماذج ذكاء اصطناعي ضخمة تعمل على خوادم، وتستطيع «اختراع» تفاصيل غير موجودة (مثل ملامح وجه واضحة من صورة ضبابية جداً). هذا التطبيق يحسّن التفاصيل الموجودة فقط، لكنه مجاني وخاص بالكامل.
